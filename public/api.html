Integración para Claude Desktop, Cursor & Agentes Autónomos

Documentación API & Servidor MCP para Agentes de IA

Ejecuta generación de códigos QR vectoriales de alta definición y consulta de plantillas especializadas mediante el estándar Model Context Protocol (MCP) y REST API.

Protocolo Oficial

Servidor MCP (@qrbey/mcp)

Ver Repositorio MCP

Integra QRbey como un tool nativo en Claude Desktop, Smithery, Cursor o cualquier agente compatible con Model Context Protocol. Permite que el modelo de IA genere y devuelva enlaces QR directamente durante la conversación.

Schema de la Herramienta (generate_qr): 
{
  "name": "generate_qr",
  "description": "Genera un código QR para un negocio de barrio (restaurante, salón, comercio). Devuelve la URL de la imagen.",
  "inputSchema": {
    "type": "object",
    "properties": {
      "text": {"type": "string", "description": "URL o texto a codificar"},
      "vertical": {"type": "string", "enum": ["restaurante", "salon", "comercio", "generico"]},
      "style": {"type": "string", "enum": ["default", "con-logo", "vectorial"]}
    },
    "required": ["text"]
  }
}

Endpoints REST Disponibles

Base URL: https://qrbey.onrender.com/api

Método Ruta Descripción Acceso
POST /generate Genera código QR en PNG o SVG según configuración. Público / Token
GET /config Devuelve parámetros, límites y precios de los planes. Público
GET /health Diagnóstico de estado y uptime de la plataforma. Público

Ejemplo de Solicitud (cURL)

curl -X POST https://qrbey.onrender.com/api/generate \\
  -H "Content-Type: application/json" \\
  -d '{
    "text": "https://mi-restaurante.com/menu",
    "vertical": "restaurante",
    "style": "vectorial"
  }'
